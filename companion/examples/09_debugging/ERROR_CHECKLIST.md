# Fast error checklist

1. Read the first error, not the final cascade.
2. Inspect the stated line and the line immediately before it.
3. Check braces and matching `begin`/`end` names.
4. Check command spelling and required packages.
5. Check file names, capitalisation, and relative paths.
6. Run `latexmk -C main.tex`, then rebuild.
7. If needed, copy the problem into `main.tex` here and reduce it.
