\chapter{Method}
\label{chap:method}

We analysed 20 simulated pairs. The paired difference was
\begin{equation}
  d_i=B_i-A_i.
  \label{eq:difference}
\end{equation}
We calculated its mean and standard deviation and constructed illustrative
limits as $\bar d\pm1.96s_d$. This calculation is descriptive; an acceptability
decision additionally needs a tolerance justified by the use case.

The report was prepared from version-controlled source using \LaTeX{}'s structured
document model \parencite{lamport1994}. In a live project, the analysis script,
source data, software environment, and approvals would be archived with the
issued report.
