# Technical report template

This independent template is for a decision-oriented scientific or engineering
report. It contains a cover, document-control table, executive summary,
numbered sections, findings, recommendations, references, and appendices. All
numbers and organisations are placeholders or simulated.

Build from this directory with `latexmk -pdf main.tex`. Replace every
`[PLACEHOLDER]`, confirm the intended audience and confidentiality marking,
and verify organisational branding and approval rules before distribution.

The editable figure source is
`../../figures/original/difference_plot.tex`. Generated build files can be
removed with `latexmk -C`.
