\chapter{Supplementary material register}
\label{app:supplement}

List each deposited data, code, protocol, and supplementary file with a stable
identifier, version, licence, and access condition. Record checksums if the
discipline or repository workflow uses them. Do not place essential reasoning
only in an inaccessible supplement.

\section{Pre-deposit verification}

Confirm that file names match the thesis, sensitive material is handled under
the approved plan, and a reader can reproduce each table and figure from the
archived inputs.
