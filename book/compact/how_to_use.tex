\chapter*{Use This Book at the Keyboard}
\addcontentsline{toc}{chapter}{Use This Book at the Keyboard}

This is a coding guide, not a book to memorise. Work through it with a
\file{main.tex} file open. For each tutorial:

\begin{enumerate}
  \item type the first complete example;
  \item compile it;
  \item change one visible thing;
  \item make the stated error;
  \item repair it; and
  \item keep the working source as your own template.
\end{enumerate}

Every essential example is printed in the book. Nothing must be fetched before
you can complete a tutorial.

\begin{classroomnote}
\textbf{Companion repository name:}
\file{sinhakrishnendu/LaTeX\_for\_all}
\end{classroomnote}

Use \cref{chap:start} if you have never compiled \LaTeX{}. Jump directly to a
later chapter when you need its task. The two appendices are designed for use
beside an active project.
