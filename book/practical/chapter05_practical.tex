\section{Complete Practical Coding}
\label{sec:practical-05}

Lists and quotations should reveal structure rather than decorate prose.

\begin{latexcode}{Complete practical file: lists, quotation, and note}
\documentclass{article}

\begin{document}

\section{Selection criteria}
\begin{itemize}
  \item complete records;
  \item a valid sample identifier;
  \item measurements from both conditions.
\end{itemize}

\section{Procedure}
\begin{enumerate}
  \item Check the identifier.
  \item Record the initial value.
  \item Apply the treatment.
  \item Record the final value.
\end{enumerate}

\section{Terms}
\begin{description}
  \item[Observation] A recorded value or description.
  \item[Replicate] An independently repeated unit.
\end{description}

\begin{quote}
Use a displayed quotation only when the wording itself matters.
\end{quote}

A footnote can hold a brief qualification.\footnote{Keep essential reasoning
in the main text.}

\end{document}
\end{latexcode}

\begin{codelab}
Add one nested list only where the hierarchy is genuine. Rewrite the displayed
quotation as ordinary prose and compare the two pages.
\end{codelab}
