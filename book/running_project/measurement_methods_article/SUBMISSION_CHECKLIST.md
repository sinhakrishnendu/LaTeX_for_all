# Practice submission checklist

This checklist is for the simulated teaching article. It is not a substitute
for current journal instructions.

- [ ] Target journal, article type, and instruction access date recorded.
- [ ] All author, affiliation, correspondence, and contribution placeholders resolved.
- [ ] Anonymous package audited for names, metadata, files, acknowledgements, and links.
- [ ] `Rscript analysis/check_results.R` passes and printed values match the PDF.
- [ ] Units, equations, table, figures, captions, and cross-references verified.
- [ ] Citation records checked against authoritative sources.
- [ ] Funding, interests, ethics, data, code, and assistance statements are accurate.
- [ ] Supplementary files are named, cited, licensed, and documented.
- [ ] Clean source folder builds with `latexmk -pdf main.tex`.
- [ ] Build log, fonts, links, metadata, and every page of the PDF inspected.
- [ ] Exact source, PDF, supplement, manifest, and submission proof archived.
