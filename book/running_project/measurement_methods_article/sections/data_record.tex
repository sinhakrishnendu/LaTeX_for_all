\section{Simulated data record}
\label{app:data}

The complete values are stored in
\texttt{data/simulated\_measurements.csv}; the verification code is
\texttt{analysis/check\_results.R}. The files are educational and contain no
observations from people, animals, instruments, or field sites.

The document was prepared in \LaTeX{}; maintained documentation is available from
the \LaTeX{} Project \parencite{latexprojectDocumentation}.
