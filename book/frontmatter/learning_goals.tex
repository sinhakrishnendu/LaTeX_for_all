\chapter*{What you will be able to do}
\addcontentsline{toc}{chapter}{What you will be able to do}

By the end of the book, you should be able to:

\begin{itemize}
  \item explain how source files, document classes, packages, compilers, and
        PDF output work together;
  \item create and organise a portable multi-file \LaTeX{} project;
  \item write clear prose, mathematics, quantities, tables, figures,
        cross-references, citations, and bibliographies;
  \item diagnose common errors by reading the log and reducing a problem to a
        minimal working example;
  \item build a publication-ready generic scholarly manuscript;
  \item adapt a complete thesis or dissertation without inventing or ignoring
        institutional requirements;
  \item prepare a professional technical or scientific report; and
  \item proof, archive, reproduce, and package source for submission.
\end{itemize}

These goals describe independent practice. You should not merely recognise a
command when you see it; you should be able to decide whether it belongs in
your document and test that it behaves as intended.
