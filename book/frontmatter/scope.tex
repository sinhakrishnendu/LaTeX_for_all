\chapter*{What this book covers---and what it does not}
\addcontentsline{toc}{chapter}{What this book covers---and what it does not}

This book teaches the complete working path from a first source file to a
carefully checked article, thesis, or technical report. Its primary scope is
practical document preparation: structured prose, mathematics and units,
tables, figures, automatic references, bibliographies, multi-file projects,
error diagnosis, reusable document organisation, and final PDF checks. Every
chapter now ends with a complete practical coding section that can be compiled
before the longer explanation is revisited.

The book does not attempt advanced macro or class programming, TikZ drawing,
Beamer presentation design, multilingual publishing systems, or the specialist
production workflow of every publisher. Those are substantial subjects in
their own right. The generic patterns here prepare readers to understand and
adapt a verified local, institutional, journal, or publisher specification
without claiming to replace it.

The companion repository is named
\file{sinhakrishnendu/LaTeX\_for\_all}. It is optional: every essential example
and instruction needed to follow the book is printed in these pages.

\section*{Opening-page design}

Part-title pages always open on a right-hand (recto) page. Individual chapters
begin on the next available page. This is a deliberate economical-paperback
choice: it preserves strong part divisions without adding a blank leaf before
every chapter.
