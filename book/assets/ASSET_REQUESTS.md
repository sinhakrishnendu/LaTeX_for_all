# Asset requests and provenance

## Optional assets for a future illustrated edition

The current book explains software operations without screenshots and remains
usable when interfaces change. For a later illustrated edition,
capture original screenshots close to publication and verify permission to
reproduce them.

1. **Overleaf project editor (optional)** - show the file tree, `main.tex`,
   source editor, Recompile control, PDF preview, and logs control. Capture
   from an author-owned demonstration project with no personal information.
2. **Overleaf download menu (optional)** - show separate source and PDF
   download actions. Recheck the interface immediately before capture.
3. **TeXstudio build view (optional)** - show source, PDF preview, and the
   first meaningful log error. Use a deliberately created local project.
4. **Visual Studio Code with LaTeX Workshop (optional)** - show source and
   preview only if the final chapter needs editor comparison.
